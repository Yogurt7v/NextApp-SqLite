# NextApp - Мероприятия

Полнофункциональное веб-приложение для создания и управления мероприятиями, построенное с использованием современных технологий React.

## 🚀 Основные возможности

### Для участников

- **Просмотр мероприятий**: Отображение списка предстоящих мероприятий с подробной информацией
- **Присоединение/отсоединение**: Кнопка для присоединения к мероприятию или выхода из него
- **Карточки мероприятий**: Удобный интерфейс просмотра мероприятий в виде карточек

### Для организаторов

- **Создание мероприятий**: Форма для создания нового мероприятия с обязательными полями (название, дата)
- **Редактирование мероприятий**: Возможность изменения информации о мероприятии
- **Управление участием**: Просмотр списка участников мероприятия

## 🏗 Архитектура

Проект использует **Feature-Sliced Design (FSD)** - методологию для структурирования React приложений:

```
src/
├── app/              # Глобальные стили и конфигурации
├── entities/         # Бизнес-сущности (Event, User)
├── features/         # Функциональность (create-event, join-event, etc.)
├── pages/            # Страницы приложения Next.js
├── shared/           # Переиспользуемый код (API, утилиты)
└── server/           # Серверная логика (tRPC, DB)
```

### Ключевые слои:

- **Entities**: Бизнес-сущности с UI компонентами
- **Features**: Реализация конкретных функций пользователя
- **Shared**: Переиспользуемый код и логика
- **Pages**: Структура маршрутизации Next.js

## 📦 Установка и запуск

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/Yogurt7v/NextApp-SqLite.git
   cd NextApp-SqLite/app
   ```

2. **Установите зависимости:**

   ```bash
   npm install
   ```

3. **Настройте базу данных:**

   ```bash
   npx prisma generate
   npx prisma db push
   ```

4. **Запустите приложение:**

   ```bash
   npm run dev
   ```

5. **Откройте в браузере:**
   ```
   http://localhost:3000
   ```

## 📊 Модель данных

### Пользователь (User)

- ID, имя, email, пароль
- Связь с созданными мероприятиями
- Связь с участием в мероприятиях

### Мероприятие (Event)

- ID, дата создания/обновления
- Название, описание, дата проведения
- Ссылка на организатора
- Список участников через модель Participation

### Участие (Participation)

- Many-to-Many связь между пользователями и мероприятиями
